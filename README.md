VetNexa — Frontend UI/UX Design
=================================

This folder contains the frontend UI/UX design deliverables for VetNexa: a premium, modern livestock health platform. All files are static prototypes and design documentation (no backend code).

Created items:
- `style-guide.md` — design tokens, colors, typography, spacing, animations
- `logo.svg` — minimal VetNexa logo (SVG)
- `prototypes/` — static HTML/CSS/JS prototypes for core screens

How to preview:
1. Open the HTML files in `prototypes/` in your browser (e.g., `prototypes/landing.html`).
2. The prototypes are static and use `prototypes/styles.css` and `prototypes/scripts.js` for visuals and micro-interactions.

Design scope: Visual design, interactions, animations, responsive layouts, and UX flow only. No backend, APIs, or auth logic is included.
