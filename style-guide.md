VetNexa Style Guide — Core Tokens
================================

1) Color System
- Primary: Light Green / Fresh Mint — #66CDAA (accent: #4FC799)
- Secondary: Light Blue / Sky Blue — #70CFF2 (accent: #4AB9E6)
- Background: Very light green-blue tinted white — #F6FBFB
- Surface: Pure white — #FFFFFF
- Text: Dark charcoal / deep blue-gray — #0F2130
- Secondary text: Soft gray — #8B97A6
- Status: Green (Low) — #27AE60, Amber (Attention) — #F29E4C, Red (Critical) — #E85D5D

Notes: Keep colors soft and professional; use subtle green→blue gradients only for hero accents.

2) Typography
- Font stack: Inter, system-ui, -apple-system, "Segoe UI", Roboto, "Helvetica Neue", Arial
- Headings: 600–800 weight; clear, confident
- Body: 400–500 weight; comfortable line-height (1.5)
- Numbers/statistics: larger size, heavier weight for emphasis

Scale examples:
- H1: 40px / 56px line-height / 700
- H2: 28px / 40px / 700
- H3: 20px / 28px / 600
- Body: 16px / 24px / 400
- Small: 13px / 20px / 400

3) Spacing & Layout
- Base spacing unit: 8px
- Radii: 10px primary, 6px small
- Shadows: subtle (e.g., 0 6px 20px rgba(16,24,40,0.06))

4) Buttons
- Primary filled: mint background, white text, soft shadow, slight lift on hover
- Secondary outline: white background, blue border, subtle hover
- Ghost: minimal for tertiary actions

5) Cards
- Use white surface with 10px radius, minimal border, subtle elevation on hover
- Keep content spacious; avoid cramped grids

6) Navigation
- Slim left sidebar for desktop with icons + text; active state has soft green/blue background and animated indicator
- Mobile: top header + hamburger and bottom nav for primary actions

7) Animations
- Duration: 200–400ms for most micro-interactions; 200–500ms for more pronounced
- Easing: cubic-bezier(.2,.9,.2,1) (smooth, non-bouncy)
- Page entrance: fade + translateY(8–16px)

8) Icons & Illustrations
- Line + filled combination, minimal strokes, friendly rounded corners
- Use small decorative shapes inspired by health, livestock, location, data

9) Responsive rules
- Desktop: full sidebar + spacious layout
- Tablet: collapsible sidebar
- Mobile: stacked single-column, touch-friendly controls, bottom nav

10) Accessibility
- Maintain contrast ratios for text and critical UI
- Focus states for keyboard navigation
